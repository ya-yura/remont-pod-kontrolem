# Ремонт под контролем

Статический лендинг организатора ремонта: HTML, CSS, JavaScript. Node.js 22+ нужен для сборки и локального сервера. Зависимостей нет.

## Запуск

Выполнить `npm run check`, `npm run build`, `npm start`. Открыть http://127.0.0.1:4173. Production-файлы находятся в dist/. GitHub Actions публикует main на Pages.

## Структура

Hero → преимущества → этапы → контроль и доверие → границы ответственности → FAQ → форма → контакты. Все CTA ведут к простой форме. index.html содержит тексты, styles.css — адаптивность, app.js — поведение, config.js — настройки. assets/ содержит фото, scripts/ — сборку и проверки.

## Настройка перед запуском рекламы

В config.js указать реальные имя, город, телефон, Telegram и formEndpoint — действующий HTTPS адрес Formspree. Без endpoint форма сообщает о недоступности, не отправляет данные и не имитирует успех. Для Telegram-бота нужен backend; секреты во фронтенде запрещены. После настройки отправить контрольную заявку.

Реальный адрес не предоставлен; бизнес невозможно идентифицировать по описанию. Поэтому карта не показывает случайную точку. mapEmbed принимает официальный URL https://yandex.ru/map-widget/..., mapDirections — ссылку маршрута. При заполнении появляется адаптивный виджет.

Перед сбором заявок добавить фактическую политику обработки данных и реквизиты оператора. Предложенные механизмы работы согласовать с условиями договора.

Отзывы, показатели, реальные кейсы и фотографии до/после отсутствуют. Вместо выдуманных доказательств опубликованы механизмы контроля. Реальные материалы можно добавить в #control. Фото интерьера — иллюстрация, не собственный кейс. Источник: https://www.pexels.com/photo/1571460/ . Изображение хранится локально, около 171 КБ.

Оценены Kokonut UI, React Bits, DaisyUI, Backlit UI, Magic UI, Anime.js, Rive: для этого статического сайта библиотеки избыточны. Нативные details, IntersectionObserver и CSS обеспечивают нужные взаимодействия без зависимостей. Есть prefers-reduced-motion, системные шрифты, lazy loading нижнего фото. Core Web Vitals требуют полевых замеров.
